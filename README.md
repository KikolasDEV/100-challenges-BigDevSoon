# 100-challenges-BigDevSoon

Repositorio de retos UI (frontend) basados en **BigDevSoon** para practicar **maquetación profesional**, responsive real, detalle visual y consistencia.  
Objetivo: construir interfaces con estándar de trabajo real (no “pantallas bonitas” sin criterio).

## 🎯 Objetivos
- Dominar HTML semántico y CSS (layout, spacing, responsive).
- Integrar TailwindCSS como herramienta de productividad (sin perder fundamentos).
- Publicar retos con documentación y evidencia (capturas y demo cuando aplique).

## 🧭 Roadmap relacionado
Este repositorio cubre práctica de UI/maquetación dentro del roadmap frontend (Tailwind + BigDevSoon).

## 🔗 Recurso principal
- BigDevSoon Challenges: https://app.bigdevsoon.me/challenges

## 🧰 Stack
- HTML
- CSS / TailwindCSS (según el reto y la fase del roadmap)
- JavaScript (solo si el reto lo requiere)

## ✅ Estándares de calidad
Cada challenge publicado debe cumplir:
- Responsive real (mobile + desktop).
- Estados `hover` / `focus` trabajados.
- Accesibilidad mínima: semántica, labels cuando aplique, focus visible.
- README propio con:
  - objetivo
  - decisiones técnicas
  - capturas
  - enlace a demo (cuando exista)

## 🗂️ Estructura
- `README.md` (índice general)
- `challenge-01-<nombre>/`
  - `README.md`
  - `src/` (o estructura del proyecto)
- `challenge-02-<nombre>/`
  - `README.md`
  - `src/`
- ...

> Aunque el repositorio se llame “100 challenges”, se prioriza **calidad sobre cantidad**.

- Si se usa tooling (Vite u otro): se documentará en el `README.md` del challenge.
